# Траты по чекам

Мобильное веб-приложение (PWA) для учёта трат по фото чеков.

- Фотографируете чек, приложение разбирает его на позиции и категории.
- Распознавание через Claude API по вашему собственному ключу или бесплатно, прямо на телефоне (Tesseract).
- Все чеки, фото и ключ хранятся только на устройстве (IndexedDB и localStorage). Своего сервера у приложения нет.
- Аналитика по категориям, самые дорогие и самые частые покупки.
- Устанавливается на главный экран, работает офлайн (кроме распознавания).

## Как это собирается

При каждом пуше в `main` GitHub Actions (`.github/workflows/build.yml`):

1. собирает веб-версию из `web/` в `www/` и публикует её на GitHub Pages;
2. кладёт рядом пакет обновления `updates/bundle-<версия>.zip` и `update.json`;
3. собирает APK (Capacitor) и выкладывает его в релиз `apk`.

APK при запуске проверяет `update.json`, скачивает новую версию и включает её при следующем открытии
(модуль `@capgo/capacitor-updater`, без внешних серверов). Если новая версия не запустилась, приложение откатывается на прошлую.

Переустанавливать APK нужно только при изменениях в `android/` или нативных модулях.

## Локальная разработка

```
npm install
npm run build:web
cd www && python3 -m http.server 8000
```

Ключ подписи в `android/keystore/` общий и подходит только для личного использования.
Перед публикацией в Google Play замените его на приватный ключ, хранящийся вне репозитория.

## Структура

- `web/index.html`, `web/styles.css` — интерфейс
- `web/js/app.js` — экраны и логика
- `web/js/db.js` — хранение на устройстве
- `web/js/recognize.js` — распознавание (Claude API и бесплатный режим)
- `web/js/native.js` — камера, сохранение файлов и самообновление в APK
- `web/sw.js`, `web/manifest.webmanifest`, `web/icons/` — установка веб-версии и офлайн-режим
- `android/` — Android-проект Capacitor
- `scripts/build-web.mjs` — сборка `www/` с номером версии
