# Траты по чекам

Мобильное веб-приложение (PWA) для учёта трат по фото чеков.

- Фотографируете чек, приложение разбирает его на позиции и категории.
- Распознавание через Claude API по вашему собственному ключу или бесплатно, прямо на телефоне (Tesseract).
- Все чеки, фото и ключ хранятся только на устройстве (IndexedDB и localStorage). Своего сервера у приложения нет.
- Аналитика по категориям, самые дорогие и самые частые покупки.
- Устанавливается на главный экран, работает офлайн (кроме распознавания).

## Как запустить локально

Любой статический сервер из корня репозитория, например:

```
python3 -m http.server 8000
```

## Структура

- `index.html`, `styles.css` — интерфейс
- `js/app.js` — экраны и логика
- `js/db.js` — хранение на устройстве
- `js/recognize.js` — распознавание (Claude API и бесплатный режим)
- `sw.js`, `manifest.webmanifest`, `icons/` — установка и офлайн-режим

При изменении файлов увеличьте `VERSION` в `sw.js`, чтобы у пользователей обновился кэш.
